# ModelFactory Beta — support

Publisher: **Tõnu Marandi**.

ModelFactory Beta is an experimental 3D workflow that requires **Blender 4.5.3**, Python and an execution-capable Work/Codex environment. Results vary by model and may need manual correction.

For installation questions, errors or model feedback, [open a GitHub issue](https://github.com/orogdor/blender-cloud-test/issues/new?template=mudelitehas-feedback.yml) or [view existing issues](https://github.com/orogdor/blender-cloud-test/issues).

Include the plugin version, requested subject and polygon budget, Blender version, operating system, the failing stage and what you expected to happen. If useful, attach a small non-sensitive screenshot or the optional local feedback bundle. The feedback helper does not submit an issue automatically.

GitHub issues and their attachments in this repository are public. Do not include passwords, tokens, private model inputs or other personal/confidential information. Review feedback bundles before uploading. Support has no promised response time or guaranteed fix date.
