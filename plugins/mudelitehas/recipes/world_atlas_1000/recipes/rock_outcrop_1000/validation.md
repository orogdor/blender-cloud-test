# Kaljupaljand – valideerimine

- [x] Päris geomeetria olemas OBJ ja GLB failis.
- [x] OBJ koosneb ainult nelinurksetest tahkudest.
- [x] 360 quadi, piir <=1000.
- [x] GLB avatud uuesti trimesh abil; 720 trianguleeritud kolmnurka.
- [x] Pivot maapinna keskosas, Y-up.
- [ ] **Mudelitehas 0.1.2 sertifikaat**: 3 sõltumatut referentssuunda ja punktide witness enne meshi (puudub).
- [ ] Blender .blend eksport / Blenderi enda reimport (siinses keskkonnas Blender puudub).
- [ ] Mängus päriselt üle vaadatud (GLB paigutuse visuaaltest mängus).

See on **protseduuriline quad-algmudel**, mitte punktipilvest rekonstrueeritud sertifitseeritud Mudelitehas 0.1.2 mudel.
