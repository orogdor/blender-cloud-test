Publisher: **Tõnu Marandi**.

## Scope and price

ModelFactory Beta is an experimental 3D modeling workflow made available for testing and feedback. The beta plugin itself is free, does not sell products and does not process payments. Separate third-party subscriptions, usage limits and charges may apply.

## Requirements

Use requires **Blender 4.5.3**, Python and an execution-capable Work/Codex environment. The included runtime installer supports Linux x64. The package does not provide a hosted Blender service or install Blender on a phone. Third-party software and services retain their own applicable terms and licenses.

No particular model quality, dimensional accuracy, animation quality or compatibility result is promised. Inspect exported files in the intended application before relying on them. A completed script or successful export check does not establish visual or manufacturing suitability.
