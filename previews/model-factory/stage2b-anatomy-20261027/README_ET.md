# ModelFactory Lab — kiviaja inimene, Stage 2B

Kohalikus arvutis loodud parandatud 3D-punktipilve katse. Kasutati varasema 2A vigaste neljavaadete põhjal koostatud PLY-d ja Stage 1 originaalpilte.

2B jooksul katsetati kolme meetodit: kehapiirkondade sügavuse eraldi korrigeerimine (v1), külgpindade ühendamine (v2) ja ümardatud anatoomiliste ristlõigete põhjal uus punktipilv (v3). V3 on parema siluetiga esialgne katse, sisaldab 197 610 3D-punkti.

**Oluline piirang:** külgvaated olid vigased. Keha tegelik sügavus, kuju ja ruumiline tekstuur on *oletatud*, mitte mitmest täpsest ortovaatest mõõdetud. See ei ole lõpuleviidud LOTRO taseme 3D-mudel, quad-mesh, GLB ega rig. Stage 2C ja mesh'i ei alustatud.

ZIP sisaldab PLY-d, skripti, JSON-metadata, nelja 3D-kontrollvaadet ja eestikeelset raportit.
