# Mudelitehas 8000 · Tase 2 · Viikingisõdalane

This is the actual web presenter for the GitHub Blender built character.

- Open the web viewer: [Viikingisõdalane](./index.html).
- Download the GLB: [viiking.glb](./viiking.glb).
- Complete Blender .blend file, reconstructed mesh and intermediate oriented point cloud are available in the [successful GitHub Actions run](https://github.com/orogdor/blender-cloud-test/actions/runs/38679044870).

Pipeline: 2D illustrated concept -> four orthographic silhouette images -> explicitly saved oriented point cloud -> Open3D Poisson reconstruction -> Blender QuadriFlow remeshing -> exactly 8000 quad body with separate axe and shield -> GLB and viewer.

The design views are illustrative and inferred, not calibrated photos. This is a stylized mesh rather than a photorealistic reproduction of the generated mood-board illustration.
